Privacy Policy — Dictionary Search

Last updated: 2026-09-24

Extension browser "Dictionary Search" membantu mencari terjemahan label multi-bahasa (Indonesia / English / Korean) dari aplikasi Kamus (dictionary) milik pengguna sendiri.

Data yang diakses

  • Data kamus via Supabase: extension membaca daftar term (terms) dari project Supabase yang dikonfigurasi pengguna (read-only, menggunakan anon key milik pengguna sendiri). Tidak ada penulisan/perubahan data.
  • Konten halaman web: di situs yang disetujui pengguna, extension membaca teks elemen bertanda EN/ID/KR dan posisi klik untuk menampilkan kotak pencarian, serta mengisi nilai pada kolom input yang sedang aktif.

Data yang disimpan

Pengaturan (daftar domain target, Supabase URL, anon key) disimpan lokal di chrome.storage.sync / browser.storage.sync milik pengguna.

Data yang tidak dikumpulkan

  • Extension tidak mengirim data ke server pihak ketiga mana pun.
  • Tidak ada tracking, analitik, maupun pengumpulan data pribadi.
  • Konten halaman yang dibaca hanya dipakai pada sesi tersebut untuk fitur pencarian.

Kontak
